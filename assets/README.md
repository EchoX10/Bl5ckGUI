## 📐 Especificações recomendadas

Pra manter o README leve e com boa qualidade, segue o padrão:

| Tipo | Formato | Resolução | Tamanho máx. |
|------|---------|-----------|--------------|
| **Preview (GUI)** | `.png` | 1200×800 | 500 KB |
| **Logo** | `.png` (fundo transparente) | 512×512 | 100 KB |
| **Banner** | `.png` ou `.webp` | 1920×400 | 300 KB |
| **GIFs de demo** | `.gif` ou `.webp` | 800×600 | 2 MB |

> 💡 **Dica:** use [TinyPNG](https://tinypng.com) ou [Squoosh](https://squoosh.app) pra comprimir antes de subir. README pesado carrega lento no mobile.
